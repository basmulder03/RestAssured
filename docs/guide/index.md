# User guide

Task-oriented guides for everyone who uses RestAssured in a club. Also available in
[Dutch](/nl/handleiding/).

::: info Coming with the first release
:::

## Planned guides

- **Everyone with an account:** logging in with a link, switching between clubs
- **Quartermasters / instrument managers:** adding assets and members (members don't need an
  account), lending and returning, recording damage, labels and
  scanning, importing your existing spreadsheet
- **Treasurers:** reading the forecast, adjusting assumptions, freezing a budget for the general
  meeting, insurance overview
- **Club admins:** club colours and logo, roles and permissions, inviting members, issuing login
  and reset links, anonymizing former members
- **Platform admins:** creating and managing clubs
