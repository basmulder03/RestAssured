# Contributing

Contributions are welcome under the AGPL-3.0-or-later licence, with a DCO sign-off on each commit
(`git commit -s`).

- Start with the project rules in `CLAUDE.md` and `CONTRIBUTING.md` in the repository root.
- Architectural changes start with an [ADR](/architecture/decisions/).
- Dependencies must be free and have a licence on the
  [allow-list](/architecture/decisions/ADR-0009-licensing-dependency-policy).

Development setup instructions will follow once the application scaffold lands.
