# Security Policy

RestAssured stores personal data of club members. Please report vulnerabilities privately.

## Reporting

Use GitHub's **private vulnerability reporting** ("Security" tab → "Report a vulnerability") on this
repository. Please don't open public issues for security problems.

Include: affected version or commit, steps to reproduce, and impact (especially anything
that crosses tenant boundaries or exposes personal data).

This is a volunteer project. We aim to acknowledge reports within 7 days.

## Supported versions

Before v1.0 only the latest `main` is supported.

## Self-hosters

Operators are responsible for keeping their instance updated, for TLS, and for backups. See the
self-hosting section of the documentation.
